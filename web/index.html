Settings

Core AI
Stored only on this device. The base brain. Used for everything that has no specialist model. Leave as is. If the browser blocks direct calls (CORS), put your relay address here.
Smart model switching
Orion picks a model by task (free, no extra call): pictures → Image analysis, programming → Coding, writing/translating → Text, everything else → Core. Leave a slot's model empty to use Core. API address / key empty = same as Core. If a specialist fails, Orion retries with Core automatically.
Image analysis NVIDIA accepts about 180 KB inline. Raise only for other providers.
Coding
Text & writing
Other providers (OpenRouter, Groq…) need an OpenAI-compatible address such as https://openrouter.ai/api/v1 and allow browser calls.
Web access
Works without any key: DuckDuckGo through your relay, else Wikipedia. Links you paste are read automatically. The globe button forces a search for one message.
Voice
Auto follows the language of your last message.
Appearance & logo
The logo shows in the app. For the iPhone home-screen icon, remove the app from the Home Screen and add it again.
Pictures & limits
If it fails, Orion draws with SVG instead.
Backup
Moves chats, memory, personality and settings (not API keys) to another device.

AI personality

Say “remember that …” in chat to add, “forget …” to remove, “what do you remember” to list. Facts like “I live in …” are saved automatically while learning is on. Saying “shorter” or “no emojis” updates the settings above.
